# Diverse Lightning - Minecraft Addon

A Minecraft Bedrock Edition addon that adds diverse lightning effects to the game.

## Installation

1. Download both the behavior pack and resource pack
2. Place the `behavior_pack` folder in your Minecraft behavior packs directory
3. Place the `resource_pack` folder in your Minecraft resource packs directory
4. Enable both packs in your world settings
5. Start or reload your world

## Features

- Custom lightning effects
- Enhanced weather systems
- More diverse storm patterns

## Development

This addon consists of two main components:

### Behavior Pack
Contains the logic and functionality of the addon:
- JavaScript scripts for custom behavior
- Entity definitions
- Item behaviors
- Custom recipes and loot tables

### Resource Pack
Contains the visual and audio assets:
- Custom textures
- 3D models
- Sound effects
- UI elements
